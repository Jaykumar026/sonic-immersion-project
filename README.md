# 🎧 Sonic Immersion

> An interactive web experience focused on immersive audio, modern UI design, and responsive user interaction.

## 📌 Overview

Sonic Immersion is a frontend web project built to explore immersive and interactive web experiences.

The project focuses on combining a modern user interface with audio-focused interaction while keeping the experience clean, responsive, and engaging.

## ✨ Features

- 🎧 Audio-focused interactive experience
- 🖥️ Modern and responsive user interface
- ⚡ Fast frontend development with Vite
- 🎨 Utility-first styling with Tailwind CSS
- 🧩 Reusable UI components
- 📱 Responsive design for different screen sizes

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| ⚛️ React | Frontend UI |
| 📘 TypeScript | Type-safe development |
| ⚡ Vite | Development & build tool |
| 🎨 Tailwind CSS | Styling |
| 🧩 shadcn/ui | UI components |
